01 What data can I see on the administrator page?

Almost all. You can see some basic data on the home page, such as the number of users and the number of tasks. The navigation bar lists the entry of detailed information: user information, task information, operation record and donation record.

02 What is the operation record?

The operation record is a tool that we prepare for administrators to quickly grasp what users have done. It records the user's operations, such as account activation, personal information modification, task creation, etc. You can see the latest 20 entries on the home page and all on the 'Operation Record' page.

03 What should I do through the administrator page?

As an administrator, your most important task is to approve user accounts. You can see all the information of the user in 'User Control' - 'see details', click the link 'User's file' to browse all the uploaded files, and select whether they passed or failed the review. The audit status can be changed at any time. It is used to restrict users' use of website functions.

04 How can I add a new admin?

First, this requires an existing administrator account. Then enter the 'Admin Manual' page (that is, this page). There is a 'Add Admin' link at the top of the page. Click it and enter the email address and password.
